# Brand Image Assets

Drop your tenant's images here. Filenames referenced in `tenant.config.ts`:

- `logo.png` — main logo (used in header, footer, og:image fallback)
- `hero.png` — homepage hero image (recommended 1600x900)
- `about.png` — about page portrait/studio shot

Optional gallery images (paths configurable in `tenant.config.ts > gallery`):
- Add as many as you like, reference them in config by filename

All images served from `/img/<filename>` on the deployed site.
